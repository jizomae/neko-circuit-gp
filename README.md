# NEKO CIRCUIT GP

猫ドライバーたちがデフォルメカートで競う、ブラウザ向け3Dレーシングゲームです。

## 遊び方

- `WASD` / 矢印キー: 走行・ステアリング
- `Space`: ドリフト
- `R`: コース復帰
- スマートフォン: 画面下のタッチボタン

`dist/index.html` を静的サイトとして配信すると遊べます。GitHub Pagesでは、公開元を `main` ブランチの `/dist` に設定してください。

## 技術

Three.js / WebGL / Vanilla JavaScript。サーバー処理やユーザーデータ収集はありません。
